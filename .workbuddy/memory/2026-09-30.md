- 用户自行配置了线上 BILI_COOKIE secret（health 返回 anonymous:false 佐证生效）
- **线上验证结论（全部通过）**：未登录 / 与 /api → 404 + cf-error-details 伪装页；/api/health 公开 200；
  POST /adm/login 正确 token → 200 + Set-Cookie（HttpOnly/SameSite=Strict/Secure/Max-Age=86400 属性正确）；
  带 Cookie GET / → 200 JSON 自描述；Bearer 过认证层到达业务；GET /ui → 200（52KB）
- **两个坑（排障经验）**：
  1. curl -D 提取 Set-Cookie 时必须 tr -d '\r'——响应头 CRLF 残留会让 Cookie 值尾部带 \r，HMAC 校验必失败（表现为"带 Cookie 仍 404 伪装"，我误排一轮）
  2. 该域名链路对**未压缩大响应**不稳定（/ui 52KB 裸传必断流 HTTP 000，/ 20KB 时好时坏，小 JSON 无碍）；
     加 `--compressed`（gzip）后稳定——浏览器自动协商压缩所以实际使用无感；用 curl 调试时务必带 --compressed
- 视频详情线上实测返回 HTTP 429 / code=-412（request was banned）——B 站账号级风控波动，符合 AGENTS.md 已知风险，
  服务正确识别并如实返回（非伪成功），非部署问题
